# ShipTrack: відповідність вимог архітектурним рішенням

- Доставка з першої спроби не менше 95%: розрахунок ETA, сповіщення одержувача, зміна часового інтервалу до виїзду кур'єра, маскований дзвінок одержувачу.
- Планування не більше 15 хв: окремий сервіс маршрутизації на OR-Tools з урахуванням часових інтервалів і заторів.
- Зменшення втрат посилок: журнал подій з фіксацією кожної передачі відповідальності скануванням штрихкоду.
- Перерахування наступного робочого дня: автоматичне формування реєстру перерахування та інтеграція з платіжним провайдером.
- Доступність 99,9% (NFR-5): Cloud SQL у режимі високої доступності, сервіси без стану в кількох зонах.
- Потрійний сезонний пік (NFR-4): автоматичне масштабування Cloud Run, асинхронна обробка через чергу.
- Робота без зв'язку (NFR-6): offline-first застосунок кур'єра з ідемпотентною синхронізацією.
- Захист персональних даних (NFR-8): шифрування, маскування телефонів, row-level security, знеособлення за розкладом.
- Стійкість до збоїв інтеграцій (NFR-10): transactional outbox, черга повідомлень, повторні спроби, резервні провайдери.
- Бюджет MVP і невелика команда: модульний моноліт замість мікросервісів, керовані хмарні сервіси замість власної інфраструктури.
- Моніторинг досягнення цілей: метрики й алерти Cloud Monitoring для показників цілей, фактичні значення відображаються на оперативній панелі.
