# RAG-асистент ShipTrack

Демонстраційний прототип Retrieval Augmented Generation для дисципліни
«Моделі і методи розробки програмного забезпечення».

Консольний чат відповідає на запитання про інформаційну систему ShipTrack
(кур'єрська служба доставки «останньої милі») на основі документації з
каталогу `knowledge_base`. Для порівняння можна отримати відповідь тієї самої
моделі без контексту.

## Встановлення

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

У файлі `.env` вкажіть свій `OPENAI_API_KEY`.

## Запуск

```bash
python rag_chat.py          # інтерактивний чат
python rag_chat.py --demo   # тестові запитання з RAG і без RAG, результат у demo_results.md
```

Під час першого запуску будується векторний індекс (`index.json`). Повторно
він будується лише після зміни документів у `knowledge_base`.

## Команди чату

| Команда | Дія |
|---|---|
| `<запитання>` | відповідь з RAG і перелік джерел |
| `/norag <запитання>` | відповідь без контексту |
| `/compare <запитання>` | обидві відповіді поруч |
| `/sources` | знайдені фрагменти та їх подібність |
| `/k <число>` | кількість фрагментів контексту |
| `/reindex` | перебудувати індекс |
| `/exit` | вихід із підсумком витрат |

## Структура

```
rag_chat.py        увесь код прототипу
knowledge_base/    документація ShipTrack (7 файлів Markdown)
requirements.txt   залежності
.env.example       приклад налаштувань
```

## Вартість

Індексування бази знань коштує близько 0,0001 USD, одне запитання з RAG
на моделі gpt-4o-mini близько 0,00025 USD. Ціни задано в `.env` і
використовуються лише для оцінки витрат у консолі.
